# Foxora Wallet Checker

Check if a wallet is on the Foxora GTD or FCFS allowlist for the free mint on **17 November 2026** (Robinhood Chain).

- GTD mint: 13:00 UTC
- FCFS mint: 14:00 UTC
- Public mint: 15:00 UTC (leftovers only)
- Price: free (0 ETH + gas), 1 fox per wallet

The check runs entirely in the browser. No wallet connection, nothing is sent or stored.

## Deploy

Static site — no build step. Import this repo in Vercel (or any static host) and deploy. `index.html` at the root is the whole site.
